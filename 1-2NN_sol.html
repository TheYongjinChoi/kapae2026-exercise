Part 1. 선형회귀에 은닉층 넣어보기

Task 1. 항등 활성화 은닉층 학습시키기

항등 활성화 함수를 이용해 수동으로 순전파와 역전파 알고리즘을 구현해 보겠습니다. 다음과 같은 단계로 구현이 됩니다.

  1. 순전파: 현재 가중치로 예측값을 계산합니다.
  2. 역전파: 손실을 각 가중치로 미분해 기울기를 구합니다.
  3. 갱신: 기울기의 반대 방향으로 가중치를 조금 이동시킵니다.

초기화

  • W1: 정규분포에서 무작위로 뽑는 함수 이름과, 필요한 값의 개수를 채웁니다. 예측변수마다 유닛마다 하나씩 필요하므로 p × 은닉층 유닛 수만큼입니다.
  • b1: 0을 몇 번 반복할지 채웁니다. 은닉층 유닛 하나에 편향 하나입니다.
  • w2: 몇 개를 뽑을지 채웁니다. 은닉층 유닛 5개를 받아 합치므로 유닛 수만큼입니다.

반복문

  • for: 몇 번 반복할지 채웁니다. 위에서 정의해 둔 객체 이름입니다.

순전파

  • Z: x_train과 행렬곱할 가중치 객체를 채웁니다. 입력에서 은닉층으로 가는 쪽입니다.
  • H: 활성화 함수를 통과한 결과를 채웁니다. 여기서는 항등함수이므로 통과 전과 같습니다.
  • loss_history[iter]: 실제값과 비교할 예측값 객체를 채웁니다.

역전파

  • dpred: 예측값에서 빼야 할 실제값 객체를 채웁니다. 훈련 데이터의 결과변수입니다.
  • grad_w2: t(H)와 행렬곱할 객체를 채웁니다. 바로 위에서 계산한 값입니다.
  • dZ: 항등함수는 도함수가 1이므로, 은닉층으로 전달된 값을 그대로 받습니다. 그 객체 이름을 채웁니다.
  • grad_W1: 전치해서 dZ와 곱할 객체를 채웁니다. W1에 곱해지던 값입니다.

갱신

  • W1, b2: 각 파라미터에 대응하는 기울기 객체를 채웁니다. 이름이 짝을 이룹니다.

  # b2의 기울기: b2는 모든 관측치의 예측에 1씩 기여하므로 dpred를 그대로 더합니다.
  grad_w2 <- as.vector(t(H) %*% _____)
  grad_b2 <- sum(dpred)

  # 여기서부터 은닉층입니다. 은닉층에는 정답이 없으므로,
  # 출력 쪽에서 계산한 신호를 되돌려 받아야 합니다.
  # pred = b2 + H1*w2[1] + ... + H5*w2[5] 이므로 H로 미분하면 w2만 남습니다.
  # w2는 유닛 j가 예측에 미치는 영향의 크기이고,
  # dpred는 그 예측이 어느 쪽으로 얼마나 틀렸는지입니다.
  # 둘을 곱해야 "유닛 j를 어느 쪽으로 움직여야 손실이 주는가"가 나옵니다.
  dH <- matrix(dpred, ncol = 1) %*% matrix(w2, nrow = 1)

  # 활성화 함수를 거슬러 올라갑니다. 항등함수의 도함수는 1이므로 그대로 통과합니다.
  dZ <- _____

  grad_W1 <- t(_____) %*% dZ   # W1의 기울기: W1에 곱해지던 값이 x_train이므로 곱합니다.
  grad_b1 <- colSums(dZ)         # b1의 기울기: b2 때와 같은 논리로 유닛별(열별)로 더합니다.

  # ── 3. 갱신: 기울기 반대 방향으로 조금 이동 ─────────────
  # 기울기는 손실이 커지는 방향이므로 빼 줍니다.
  # lr(학습률)을 기울기에 곱해 한 번에 움직일 폭을 정합니다.
  # 위 기울기는 모두 갱신 전 가중치 기준이므로, 계산이 끝난 뒤 네 뭉치를 한꺼번에 적용합니다.
  W1 <- W1 - lr * _____
  b1 <- b1 - lr * grad_b1
  w2 <- w2 - lr * grad_w2
  b2 <- b2 - lr * _____
}

Task 2. ReLU로 바꾸기

Task 2의 코드에서 활성화 함수만 아래의 ReLU로 바꿔 보겠습니다. 나머지는 그대로입니다. ReLU는 입력이 0보다 크면 그 값을 그대로 내보내고, 0 이하이면 0을 내보냅니다.

\[ \text{ReLU}(z) = \max(0, z), \qquad \text{ReLU}'(z) = \begin{cases} 1 & z > 0 \\ 0 & z \le 0 \end{cases} \]

빈칸을 찾아 다음 세 곳을 수정하세요. 우선 루프 안 순전파에서 Z를 그대로 내보내지 말고 pmax(Z, 0)으로 감싸 H에 저장합니다.

그리고 역전파에서 dZ <- dH를 dH * (Z > 0)을 적용한 결과가 dZ에 저장되도록 바꿉니다. 순전파가 함수를 적용하는 자리라면 역전파는 그 도함수를 곱하는 자리입니다. 우리가 구하려는 것은 손실을 Z로 미분한 값인데, Z는 활성화 함수를 거쳐 H가 된 뒤에야 예측에 반영되므로 연쇄법칙에 따라

\[\frac{\partial L}{\partial Z} = \frac{\partial L}{\partial H} \times \text{ReLU}'(Z)\]

가 됩니다. (Z > 0)은 논리형 행렬을 반환하는데, Z의 값이 0보다 큰 경우 1, 그 외는 0으로 곱해집니다. 따라서 순전파에서 Z가 0 이하라 값이 활성화 함수를 통과하지 못한 유닛은 갱신 신호도 0이 되도록 하는 장치입니다.

set.seed(1)

# Task 2와 동일합니다. 시드도 같으므로 출발점이 완전히 같습니다.
# 따라서 이후 결과의 차이는 오직 활성화 함수에서만 옵니다.
W1 <- matrix(rnorm(p * n_hidden, sd = 0.1), nrow = p)   # 입력 -> 은닉층 (p × 5)
b1 <- rep(0, n_hidden)                                  # 은닉층 편향
w2 <- rnorm(n_hidden, sd = 0.1)                         # 은닉층 -> 출력
b2 <- mean(y_train)                                     # 출력 편향

loss_history_relu <- rep(NA, n_iter)

# ── 학습 시작 ────────────────────────────────────────────────

for (iter in 1:n_iter) {

  # ── 1. 순전파 ───────────────────────────────────────────
  Z    <- x_train %*% W1 + rep(b1, each = n)   # 은닉층 입력 (n × 5)

  # <<< 변경점 1: 활성화 함수
  # ReLU(z) = max(0, z). 음수는 0으로 잘라내고 양수만 통과시킵니다.
  # pmax()는 두 값을 원소별로 비교해 큰 쪽을 남기는 함수입니다.
  # 이 한 줄이 모형을 비선형으로 만듭니다.
  H    <- _____(_____, 0)

  pred <- as.vector(H %*% w2 + b2)             # 최종 예측값

  loss_history_relu[iter] <- mean((y_train - pred)^2)

  # ── 2. 역전파 ───────────────────────────────────────────
  dpred   <- 2 * (pred - y_train) / n          # 손실을 pred로 미분
  grad_w2 <- as.vector(t(H) %*% dpred)         # w2의 기울기
  grad_b2 <- sum(dpred)                        # b2의 기울기

  dH <- matrix(dpred, ncol = 1) %*% matrix(w2, nrow = 1)   # 은닉층으로 신호 전달

  # <<< 변경점 2: 활성화 함수의 도함수
  # 항등함수는 도함수가 1이라 dZ <- dH 였습니다.
  # ReLU는 z > 0에서 1, z <= 0에서 0이므로 (Z > 0)을 곱합니다.
  # (Z > 0)은 TRUE/FALSE 행렬이고 곱셈에서 1/0으로 취급됩니다.
  # 즉 순전파에서 잘린 유닛은 갱신 신호도 받지 못합니다.
  dZ <- _____ * (_____ > 0)

  grad_b1 <- colSums(dZ)                       # b1의 기울기

  # ── 3. 갱신 ─────────────────────────────────────────────
  W1 <- W1 - lr * grad_W1
  b1 <- b1 - lr * grad_b1
  w2 <- w2 - lr * grad_w2
  b2 <- b2 - lr * grad_b2
}

Part 3. (선택사항) 하이퍼파라미터 조정

Task 6에서 세 값을 나란히 놓았을 때 Keras 모형의 성능이 선형회귀의 성능보다 높지 않았습니다. 은닉층을 얹었는데도 성능이 따라오지 않은 것인데, 여기에는 두 가지 가능성이 있습니다. 예측변수와 결과변수의 관계가 대체로 선형이라 은닉층이 잡아낼 것이 애초에 많지 않았을 수 있고, 아니면 구조는 충분한데 학습 설정이 맞지 않아 모형이 가진 표현력을 다 쓰지 못했을 수 있습니다. Task 3에서 5까지는 단순한 신경망 모델로 노드 8개, 학습률 0.01, 규제 없음으로 고정해두고 훈련을 시켰습니다. Part 3에서는 이 값들을 하나씩 바꿔 가며 검증 손실이 어떻게 반응하는지 보고, 기본 설정에서 얼마나 나아질 수 있는지 확인합니다.

같은 구조를 반복해서 만들어야 하므로 모형 정의를 함수로 감싸두겠습니다. 아래 코드에서 정의된 build_model()은 Task 3에서 5까지 세 단계로 나눠 실행하던 구조 정의와 컴파일을 함수 하나로 묶은 것입니다. 층을 쌓고 compile()까지 마친 모형을 반환하므로 호출을 하면 학습만 남은 모형이 나옵니다.

바뀐 점은 값을 코드에 직접 쓰지 않고 인수로 빼냈다는 것입니다. units, lr, dropout, l2 네 개가 조정 대상이고, 함수 정의의 = 8, = 0.01 같은 부분은 아무것도 넘기지 않았을 때 쓰이는 기본값입니다. 예를 들어, build_model()이라고만 쓰면 Task 5와 같은 모형이 나오고, build_model(units = 128)이라고 쓰면 노드 수만 바뀐 모형이 나옵니다. 반복문 안에서 값만 갈아 끼우며 여러 모형을 만들 수 있도록 정의해둔 것입니다.

layer_dropout()과 regularizer_l2()는 Part 3에서 새로 등장합니다. 지금은 두 인수의 기본값이 모두 0이라 아무 효과가 없습니다. regularizer_l2(0)은 벌점을 걸지 않는 것과 같고, layer_dropout(rate = 0)은 노드를 하나도 끄지 않으므로 층이 있어도 통과만 시킵니다. Task 9에 가서 이 값들에 0이 아닌 수를 넘기면 그때부터 작동합니다. 미리 자리를 만들어 두었다고 보시면 됩니다.

조정할 항목이 더 생기면 같은 방식으로 인수를 하나 추가하고 기본값을 지금과 같은 동작이 되도록 두면 됩니다. 예를 들어 은닉층을 하나 더 넣고 싶다면 units2 = 0을 인수로 받아 0이 아닐 때만 층을 추가하도록 쓰면, 앞서 작성한 코드는 그대로 두고 새 실험만 얹을 수 있습니다.

build_model <- function(units = 8, lr = 0.01, dropout = 0, l2 = 0) {
  keras_model_sequential(input_shape = ncol(x_train)) |>
    layer_dense(units = units, activation = "relu",
                kernel_regularizer = regularizer_l2(l2)) |>
    layer_dropout(rate = dropout) |>
    layer_dense(units = 1) |>
    compile(
      loss = "mse",
      optimizer = optimizer_adam(learning_rate = lr),
      metrics = metric_root_mean_squared_error()
    )
}

  • 드롭아웃: 매 갱신마다 노드의 일부를 무작위로 끕니다. 특정 노드에 의존하지 못하게 만드는 장치이고, 예측 시점에는 자동으로 꺼집니다. build_model()의 dropout 인수로 비율을 넘깁니다.
  • 가중치 규제: 릿지와 같은 형태의 벌점을 가중치에 겁니다. 앞 세션의 \(\lambda\)가 l2 인수로 다시 등장합니다.

세 설정을 settings 리스트에 담고 반복문으로 돌립니다.

  • cb_es: 조기 종료 콜백을 만들어 저장합니다. 세 설정에 모두 적용합니다.
  • settings: label, dropout, l2를 담은 리스트 세 개입니다. 규제 없음, 드롭아웃 0.3, L2 0.01 순입니다.
  • build_model(): units = 128, lr = 0.01로 고정하고 dropout과 l2만 설정마다 바꿉니다.
  • fit(): epochs = 100으로 넉넉히 두고 callbacks = list(cb_es)를 넘깁니다. 조기 종료가 있으므로 100회를 다 돌지 않고 멈춥니다.

Task 10. 격자 만들기와 교차검증

  • grid: expand.grid()로 노드 수, 학습률, 드롭아웃의 모든 조합을 만듭니다. units는 8과 64, lr은 0.005와 0.02, dropout은 0과 0.3입니다.
