  2. 부트스트랩 표본에 트리를 여러 번 적합해 배깅을 직접 구현하고, ranger로 랜덤 포레스트를 실행합니다.

배깅과 부스팅을 손으로 구현할 때 기본 단위가 되는 것이 의사결정 트리를 구현하는 함수인 rpart()입니다. 그래서 Part 1에서는 rpart()의 사용법을 먼저 익히고 넘어가겠습니다. Part 2와 3이 이번 실습의 초점이고, 실습 시간이 짧기 때문에 의사결정 트리는 깊이 파고들지 않고 간략히 소개만 하겠습니다. 결과변수는 이번에도 복용 중인 처방약의 개수(rx_num_mod_6m)입니다.

Part 1. 의사결정 트리

Task 1-1. 트리 적합과 시각화

rpart() 함수를 사용해 훈련 데이터에 의사결정 트리를 적합합니다.

  • 첫 번째 인수인 공식에 rx_num ~ .을 설정합니다.
  • data에 학습에 사용할 훈련 데이터인 train_data를 지정합니다.
  • method = "anova": 결과변수가 연속형일 때 지정합니다. 분할 기준으로 잔차제곱합을 사용합니다. 결과변수가 범주형이라면 "class"를 지정하고 불순도를 기준으로 나눕니다.
  • 학습된 결과를 tree_basic에 저장합니다.
  • 잎의 개수는 sum(tree_basic$frame$var == "<leaf>")로 확인합니다. $frame은 트리의 각 노드 정보를 담은 데이터프레임이고, var 열이 "<leaf>"인 행이 잎입니다.

이어서 rpart.plot() 함수로 트리를 시각화합니다.

  • 첫 번째 인수로 훈련된 모델인 tree_basic을 지정합니다.
  • type = 2: 분할 조건을 노드 아래에 표시하는 옵션입니다.
  • extra = 101: 각 노드의 관측치 수와 비율을 함께 표시하는 옵션입니다.
  • fallen.leaves = TRUE: 잎을 같은 높이에 정렬해 구조를 읽기 쉽게 합니다.

각 박스는 노드를 의미합니다. 노드 안에 표시된 텍스트의 첫 줄은 그 노드의 예측값을 의미합니다. 우리가 예측하려는 결과변수가 복용 중인 처방약의 개수 rx_num이므로 해당 집단의 평균 처방약 개수를 의미합니다.그 아래 n=xxxx xx% 형식의 숫자는 관측치 수와 전체 대비 비율입니다.

각 노드에서 분할 조건이 참이면 왼쪽, 거짓이면 오른쪽으로 내려갑니다. 맨 위에 오는 변수가 예측 오차를 가장 많이 줄인 변수입니다.

Note참고: 기본 정지 규칙

rpart()는 아무것도 지정하지 않으면 기본 정지 규칙을 적용합니다. 노드의 관측치가 20개 미만이면 나누지 않고(minsplit = 20), 분할로 인한 오차 감소가 1% 미만이면 멈춥니다(cp = 0.01). 즉 기본값 자체가 이미 상당히 보수적인 트리를 만듭니다. 뒤에서 배깅과 부스팅을 구현할 때는 이 값들을 직접 바꿔 가며 트리의 복잡도를 조절합니다.

Task 1-3. (선택사항) 최대 트리와 가지치기

정지 규칙을 풀어 트리를 최대한 키운 뒤 교차검증으로 다시 줄여 봅니다. 하이퍼파라미터는 rpart.control() 안에서 설정하고 이를 control에 넘깁니다.

  • 복잡도 패널티 cp를 0.0001로 설정해 거의 0에 가깝게 낮춥니다. 이렇게 하면 오차를 조금이라도 줄이는 분할은 모두 허용됩니다.
  • minsplit은 10으로 설정합니다. 노드에 관측치가 10개만 있어도 나눕니다.
  • xval은 교차검증 겹의 수를 정하는 인수입니다. 10으로 설정해 10겹 교차검증을 수행합니다.
  • 결과를 tree_full에 저장합니다.

교차검증을 설정하면 그 결과가 tree_full$cptable에 저장됩니다. cptable은 rpart가 트리를 키우면서 남긴 기록으로, 행 하나가 트리 크기 하나에 대응하고 열은 다음과 같습니다.

  • CP: 복잡도 파라미터
  • nsplit: 분할 횟수
  • rel error: 훈련 데이터 오차
  • xerror: 교차검증 오차
  • xstd: 교차검증 오차의 표준오차

여기서 가지치기의 기준이 되는 것은 xerror입니다. 훈련 데이터로 계산하는 rel error는 트리가 커질수록 계속 줄어들지만, 교차검증으로 계산하는 xerror는 어느 지점에서 최소가 된 뒤 다시 커집니다. 그 반등 지점이 과적합이 시작되는 곳이므로, cptable에서 xerror가 가장 작은 행의 CP 값을 찾아 그 값으로 가지를 잘라 내겠습니다.

  • 벡터에서 최솟값의 위치를 반환하는 which.min()으로 tree_full$cptable에서 xerror가 최소인 행 번호를 찾습니다.
  • 그 행의 "CP" 열 값을 꺼내 best_cp에 저장합니다.
  • prune() 함수에 tree_full과 cp = best_cp를 넣어 가지치기를 수행하고, 결과를 tree_pruned에 저장합니다.

Part 2. 배깅과 랜덤 포레스트

배깅(bagging)은 부트스트랩 표본마다 트리를 적합한 뒤 그 예측을 평균내는 방법입니다. Breiman은 1996년 논문(링크)에서 배깅을 제안하면서, 의사결정 트리가 훈련 데이터의 작은 변화에도 예측이 크게 달라진다는 문제를 출발점으로 삼았습니다. 이 불안정성은 알고리즘 자체의 무작위성 때문이 아니라 훈련된 트리가 데이터의 작은 변화에도 민감하게 반응하기 때문입니다.

Task 2-1. 배깅 직접 구현

여기서는 배깅의 원리를 이해하기 위해 패키지에 맡기지 않고 직접 구현합니다. 다음의 세 가지 단계를 차례로 실행해보겠습니다.

  • 훈련 데이터에서 부트스트랩 표본을 여러 개 뽑습니다(복원추출).
  • 각 표본에 트리를 하나씩 적합합니다.
  • 개별 트리의 예측을 평균 내어 최종 예측을 만듭니다.

1단계. 부트스트랩 표본과 개별 트리 학습

먼저 부트스트랩 표본을 만들고 트리를 학습시킵니다. 이 과정은 for 루프로 반복합니다. for 루프는 같은 작업을 정해진 횟수만큼 반복하는 구문으로 for (b in 1:n_bag) { ... }라고 쓰면 중괄호 안의 코드가 n_bag번 실행되며 그때마다 변수 b에 1부터 n_bag까지의 값이 차례로 들어갑니다. 이 b를 인덱스로 써서 각 트리를 리스트의 서로 다른 칸에 저장합니다.

  • 30회 반복해서 훈련. 반복할 횟수로 30을 지정하고, 이걸 n_bag에 저장.
  • 매 회차마다 예측 결과를 저장하기 위해 fits에 빈 리스트를 저장해 둡니다.
  • sample() 함수로 훈련 데이터의 행 번호를 무작위로 뽑아 idx에 저장합니다. 숫자를 뽑을 대상을 지정하는 첫 번째 인수에 seq_len(nrow(train_data))을 설정해 훈련데이터에서 가능한 모든 행 번호를 나열하고, 두 번째 인수에 뽑을 개수로 nrow(train_data)를 지정합니다. replace = TRUE로 복원추출해야 부트스트랩이 됩니다.
  • idx에는 이번 회차에 뽑힌 행 번호가 담겨 있습니다. 이를 train_data[idx, ]처럼 행 인덱스로 넣어 회차별 부트스트랩 표본을 만들고 boot에 저장합니다.
  • 각 회차에서 rpart()로 트리를 적합해 fits[[b]]에 저장합니다. fits의 b번째 자리에 훈련된 트리를 넣는다는 뜻이므로, 루프가 끝나면 fits에는 30개의 트리가 담기게 됩니다.
    • 모형식은 앞에서 저장해 둔 수식 객체 form으로 설정하고, 데이터는 해당 회차의 부트스트랩 표본인 boot로 설정합니다.
    • rpart()의 하이퍼파라미터를 정하는 control 인수는 아래와 같이 설정해 분산이 큰 복잡한 트리를 만듭니다. 복잡도 파라미터 cp는 0으로 두어 오차를 조금이라도 줄이는 분할이면 모두 허용하고, minsplit은 10으로 두어 관측치가 10개만 있는 노드도 더 나누도록 합니다. 두 값 모두 트리가 최대한 깊게 자라도록 푸는 설정입니다.

2단계. 예측 합치기

다음으로 개별 트리의 예측을 하나로 합칩니다. 회귀 문제이므로 결합 방식은 단순 평균입니다.

  • sapply(fits, predict, newdata = test_data)로 모든 트리의 예측을 한 번에 계산해 pred_mat에 저장합니다. 결과는 테스트 관측치 수 × 트리 개수 크기의 행렬입니다.
    • sapply()는 리스트의 각 요소에 같은 함수를 적용한 뒤 결과를 하나로 묶어 주는 함수입니다. sapply(fits, predict, newdata = test_data)라고 쓰면 fits에 담긴 트리를 하나씩 꺼내 predict(트리, newdata = test_data)를 실행합니다. 첫 번째 인수는 반복할 대상, 두 번째는 적용할 함수이고, 그 뒤에 붙인 인수인 newdata는 함수를 호출할 때마다 그대로 전달됩니다. 앞서 for 루프로 썼던 반복을 한 줄로 줄인 것과 같습니다.
    • 트리 하나의 예측 결과는 테스트 관측치 수만큼의 값을 가진 벡터입니다. sapply()는 길이가 같은 벡터들이 모이면 이를 열 방향으로 이어 붙여 행렬로 만들어 주기 때문에 pred_mat은 테스트 관측치 수 × 트리 개수 크기의 행렬이 됩니다.
  • rowMeans()로 행별 평균을 구해 bag_pred에 저장합니다. 배깅은 같은 관측치에 대한 여러 트리의 예측을 평균을 내는 방법이므로 평균은 행 방향으로 구해야 합니다. rowMeans(pred_mat)으로 각 행의 평균을 계산해 bag_pred에 저장하면 관측치마다 하나씩, 테스트 관측치 수만큼의 최종 예측이 나옵니다.

Task 2-2. 랜덤 포레스트

랜덤 포레스트는 배깅에 훈련에 사용하는 예측변수를 무작위로 선택하는 하나의 요소를 더합니다. 분할마다 후보로 올릴 예측변수를 무작위로 제한해 트리들 사이의 상관을 낮추는 것입니다.

이 실습에서는 ranger 패키지를 사용합니다. R의 랜덤 포레스트 구현으로는 randomForest가 가장 오래됐지만, ranger는 C++를 기반으로 만들어진 후발 주자이지만, 더 다양한 기능을 제공하고, 예측변수가 많거나 표본이 클 때 더 빠릅니다.

ranger는 회귀에서 OOB(out-of-bag) MSE를 prediction.error에 담아 둡니다. 부트스트랩은 복원추출이므로 각 트리를 학습할 때 뽑히지 않은 관측치가 약 37% 남고, 이 관측치들로 추정한 오차가 OOB 오차입니다. 검증 데이터를 따로 떼지 않아도 되므로 하이퍼 파라미터 탐색에 그대로 쓸 수 있습니다. 성능 평가 단계에서는 여기에 제곱근을 취해야 RMSE가 됩니다.

  • ranger() 함수에 formula = form, data = train_data를 넣어 훈련을 실행하고 그 결과를 fit_rf에 저장합니다. respect.unordered.factors = "order"는 순서 없는 범주형 변수를 다루는 방식으로, 범주를 결과변수 평균 순으로 정렬해 분할 후보를 찾습니다. 범주 수가 많을 때 계산이 빨라지고 분할도 안정적입니다. verbose = FALSE로 훈련 과정의 출력은 끕니다.
  • fit_rf$prediction.error는 OOB(out-of-bag) 오차입니다. 각 트리를 학습할 때 부트스트랩에서 뽑히지 않은 관측치로 계산한 예측 오차로, 별도의 검증 데이터 없이도 성능을 가늠할 수 있습니다. 회귀에서는 MSE로 저장되므로 제곱근을 취해 oob_rmse_rf에 저장합니다.
  • predict()에 fit_rf와 data = test_data를 넣어 예측값을 계산하고 pred_rf에 저장합니다. ranger의 predict()는 인수 이름이 newdata가 아니라 data이고, 결과는 예측값 외에 여러 정보를 담은 리스트이므로 $predictions로 꺼내야 합니다.
  • 테스트 RMSE를 rmse_rf에 저장하고 배깅의 결과와 나란히 출력합니다. 랜덤 포레스트는 분할마다 변수를 일부만 후보로 삼아 트리 간 상관을 낮추므로, 배깅보다 오차가 조금 더 줄어드는 것이 일반적입니다.

Part 3. 부스팅

Task 3-1. 패키지없이 구현하는 부스팅

부스팅은 약한 학습기를 순차적으로 쌓아 예측을 개선하는 방법입니다. 여기서도 패키지에 맡기지 않고 그 과정을 직접 작성해 봅니다. 약한 학습기로는 분할이 하나뿐인 회귀 트리, 즉 stump를 사용합니다. Stump 하나는 예측변수 전체 중 딱 하나를 골라 한 번만 자르는 모형이므로 예측력이 매우 낮습니다. 그런 모형을 100개 쌓으면 어떻게 되는지를 살펴보는 것이 이 과제의 목적입니다.

먼저 stump 하나를 훈련 데이터에 적합해 stump1에 저장합니다.

  • rpart()에 y_train ~ .을 넣습니다. 왼쪽에는 앞에서 만든 결과변수 벡터를, 오른쪽 .에는 data로 넘긴 데이터프레임의 모든 열을 쓴다는 뜻입니다.
  • data = x_train으로 예측변수만 담긴 데이터프레임을 넘깁니다.
  • maxdepth = 1로 분할을 한 번만 하도록 강제합니다.
  • cp = 0으로 복잡도 페널티를 없앱니다. maxdepth가 이미 제약이므로 페널티까지 걸면 분할이 아예 일어나지 않을 수 있습니다.

성능은 훈련 RMSE로 확인합니다. 잔차를 계산해 주는 residuals() 함수를 쓰면 y_train - predict(stump1)을 직접 계산하지 않아도 잔차를 바로 얻을 수 있습니다. 이 잔차를 제곱해 평균 내고 제곱근을 취한 값을 rmse_stump1에 저장합니다. - 비교 기준으로 훈련 데이터의 평균만으로 예측한 영모형의 RMSE도 rmse_null에 저장합니다.

이제 부스팅의 동작을 한 번 수행합니다. 첫 stump가 설명하지 못한 부분, 즉 잔차를 새로운 결과변수로 삼아 두 번째 stump를 적합합니다.

  • residuals(stump1)로 첫 stump의 잔차를 꺼내 r1에 저장합니다.
  • rpart()에 r1 ~ .을 넣고 나머지는 그대로 두어 stump2를 적합합니다. 예측변수는 그대로이고 결과변수만 바뀌었습니다.
  • predict(stump1) + predict(stump2)로 두 예측을 더해 pred2에 저장합니다. 평균이 아니라 합입니다. 두 번째 stump가 예측하는 것은 결과변수가 아니라 첫 번째가 남긴 오차이므로, 그 오차분을 더해 주어야 원래 척도의 예측이 됩니다.

Task 3-2. 100회 반복하기

Task 3-1의 동작을 for 루프에 넣어 100번 반복합니다. 매 반복에서 직전 stump의 잔차를 꺼내 새 stump를 적합하고, 예측결과 벡터를 누적해 저장합니다. 이번에는 비교를 위해 훈련과 테스트 두 궤적을 함께 기록합니다.

1단계. 초기화

  • M에 반복 횟수 100을 저장합니다.
  • f_tr과 f_te에 각각 0을 저장합니다. 누적 예측을 담을 그릇이고, 반복마다 새 stump의 예측이 더해집니다.
  • r에 y_train을 저장합니다. 첫 반복에서 stump가 맞힐 대상입니다. 아직 아무것도 예측하지 않았으므로 잔차는 결과변수 자체입니다.
  • rmse_tr과 rmse_te에 numeric(M)으로 길이 M의 빈 벡터를 만듭니다.

2단계. 루프

  • rpart()에 ~, .을 넣어 현재 잔차에 stump를 적합합니다. 학습은 언제나 훈련 데이터로만 이루어집니다.
  • f_tr에는 predict(stump)를, f_te에는 predict(stump, newdata = x_test)를 더합니다.
  • 각각의 RMSE를 rmse_tr[m]과 rmse_te[m]에 저장합니다.
  • residuals(stump)로 다음 반복이 맞힐 잔차 r을 갱신합니다. r을 갱신하지 않으면 같은 stump를 100번 반복하게 되니 주의하세요.

# Part 1. 의사결정 트리

## Task 1-1. 트리 적합과 시각화

`rpart()` 함수를 사용해 훈련 데이터에 의사결정 트리를 적합합니다.

  - 첫 번째 인수인 공식에 `rx_num ~ .`을 설정합니다.
  - `data`에 학습에 사용할 훈련 데이터인 `train_data`를 지정합니다.
  - `method = "anova"`: 결과변수가 연속형일 때 지정합니다. 분할 기준으로 잔차제곱합을 사용합니다. 결과변수가 범주형이라면 `"class"`를 지정하고 불순도를 기준으로 나눕니다.
  - 학습된 결과를 `tree_basic`에 저장합니다.
  - 잎의 개수는 `sum(tree_basic$frame$var == "<leaf>")`로 확인합니다. `$frame`은 트리의 각 노드 정보를 담은 데이터프레임이고, `var` 열이 `"<leaf>"`인 행이 잎입니다.

이어서 `rpart.plot()` 함수로 트리를 시각화합니다.

  - 첫 번째 인수로 훈련된 모델인 `tree_basic`을 지정합니다.
  - `type = 2`: 분할 조건을 노드 아래에 표시하는 옵션입니다.
  - `extra = 101`: 각 노드의 관측치 수와 비율을 함께 표시하는 옵션입니다.
  - `fallen.leaves = TRUE`: 잎을 같은 높이에 정렬해 구조를 읽기 쉽게 합니다.

## Task 1-2. 예측과 평가

`predict()` 함수에 학습된 모델과 테스트 데이터를 입력해 예측값을 계산합니다.

  - 첫 번째 인수로 `tree_basic`을 불러옵니다.
  - `newdata`에 테스트 데이터를 지정합니다. `glmnet`과 달리 데이터프레임을 그대로 넣습니다.
  - 계산한 예측값을 `pred_tree`에 저장합니다.

## Task 1-3. (선택사항) 최대 트리와 가지치기

정지 규칙을 풀어 트리를 최대한 키운 뒤 교차검증으로 다시 줄여 봅니다. 하이퍼파라미터는 `rpart.control()` 안에서 설정하고 이를 `control`에 넘깁니다.

  - 복잡도 패널티 `cp`를 `0.0001`로 설정해 거의 0에 가깝게 낮춥니다. 이렇게 하면 오차를 조금이라도 줄이는 분할은 모두 허용됩니다.
  - `minsplit`은 `10`으로 설정합니다. 노드에 관측치가 10개만 있어도 나눕니다.
  - `xval`은 교차검증 겹의 수를 정하는 인수입니다. `10`으로 설정해 10겹 교차검증을 수행합니다.
  - 결과를 `tree_full`에 저장합니다.

교차검증을 설정하면 그 결과가 `tree_full$cptable`에 저장됩니다. `cptable`은 `rpart`가 트리를 키우면서 남긴 기록으로, 행 하나가 트리 크기 하나에 대응하고 열은 다음과 같습니다.

  - `CP`: 복잡도 파라미터
  - `nsplit`: 분할 횟수
  - `rel error`: 훈련 데이터 오차
  - `xerror`: 교차검증 오차
  - `xstd`: 교차검증 오차의 표준오차

여기서 가지치기의 기준이 되는 것은 `xerror`입니다. 훈련 데이터로 계산하는 `rel error`는 트리가 커질수록 계속 줄어들지만, 교차검증으로 계산하는 `xerror`는 어느 지점에서 최소가 된 뒤 다시 커집니다. 그 반등 지점이 과적합이 시작되는 곳이므로, `cptable`에서 `xerror`가 가장 작은 행의 `CP` 값을 찾아 그 값으로 가지를 잘라 내겠습니다.

  - 벡터에서 최솟값의 위치를 반환하는 `which.min()`으로 `tree_full$cptable`에서 `xerror`가 최소인 행 번호를 찾습니다.
  - 그 행의 `"CP"` 열 값을 꺼내 `best_cp`에 저장합니다.
  - `prune()` 함수에 `tree_full`과 `cp = best_cp`를 넣어 가지치기를 수행하고, 결과를 `tree_pruned`에 저장합니다.

# Part 2. 배깅과 랜덤 포레스트

배깅(bagging)은 부트스트랩 표본마다 트리를 적합한 뒤 그 예측을 평균내는 방법입니다. Breiman은 1996년 논문([링크](https://link.springer.com/article/10.1007/BF00058655))에서 배깅을 제안하면서, 의사결정 트리가 훈련 데이터의 작은 변화에도 예측이 크게 달라진다는 문제를 출발점으로 삼았습니다. 이 불안정성은 알고리즘 자체의 무작위성 때문이 아니라 훈련된 트리가 데이터의 작은 변화에도 민감하게 반응하기 때문입니다.

## Task 2-1. 배깅 직접 구현

여기서는 배깅의 원리를 이해하기 위해 패키지에 맡기지 않고 직접 구현합니다. 다음의 세 가지 단계를 차례로 실행해보겠습니다.

  - 훈련 데이터에서 부트스트랩 표본을 여러 개 뽑습니다(복원추출).
  - 각 표본에 트리를 하나씩 적합합니다.
  - 개별 트리의 예측을 평균 내어 최종 예측을 만듭니다.

**1단계. 부트스트랩 표본과 개별 트리 학습**

먼저 부트스트랩 표본을 만들고 트리를 학습시킵니다. 이 과정은 `for` 루프로 반복합니다. `for` 루프는 같은 작업을 정해진 횟수만큼 반복하는 구문으로 `for (b in 1:n_bag) { ... }`라고 쓰면 중괄호 안의 코드가 `n_bag`번 실행되며 그때마다 변수 `b`에 1부터 `n_bag`까지의 값이 차례로 들어갑니다. 이 `b`를 인덱스로 써서 각 트리를 리스트의 서로 다른 칸에 저장합니다.

  - `30`회 반복해서 훈련. 반복할 횟수로 `30`을 지정하고, 이걸 n_bag에 저장.
  - 매 회차마다 예측 결과를 저장하기 위해 `fits`에 빈 리스트를 저장해 둡니다.
  - `sample()` 함수로 훈련 데이터의 행 번호를 무작위로 뽑아 `idx`에 저장합니다. 숫자를 뽑을 대상을 지정하는 첫 번째 인수에 `seq_len(nrow(train_data))`을 설정해 훈련데이터에서 가능한 모든 행 번호를 나열하고, 두 번째 인수에 뽑을 개수로 `nrow(train_data)`를 지정합니다. `replace = TRUE`로 복원추출해야 부트스트랩이 됩니다.
  - `idx`에는 이번 회차에 뽑힌 행 번호가 담겨 있습니다. 이를 `train_data[idx, ]`처럼 행 인덱스로 넣어 회차별 부트스트랩 표본을 만들고 `boot`에 저장합니다.
  - 각 회차에서 `rpart()`로 트리를 적합해 `fits[[b]]`에 저장합니다. `fits`의 `b`번째 자리에 훈련된 트리를 넣는다는 뜻이므로, 루프가 끝나면 `fits`에는 30개의 트리가 담기게 됩니다.
    - 모형식은 앞에서 저장해 둔 수식 객체 `form`으로 설정하고, 데이터는 해당 회차의 부트스트랩 표본인 `boot`로 설정합니다.
    - `rpart()`의 하이퍼파라미터를 정하는 `control` 인수는 아래와 같이 설정해 분산이 큰 복잡한 트리를 만듭니다. 복잡도 파라미터 `cp`는 0으로 두어 오차를 조금이라도 줄이는 분할이면 모두 허용하고, `minsplit`은 10으로 두어 관측치가 10개만 있는 노드도 더 나누도록 합니다. 두 값 모두 트리가 최대한 깊게 자라도록 푸는 설정입니다.

**2단계. 예측 합치기**

다음으로 개별 트리의 예측을 하나로 합칩니다. 회귀 문제이므로 결합 방식은 단순 평균입니다.

  - `sapply(fits, predict, newdata = test_data)`로 모든 트리의 예측을 한 번에 계산해 `pred_mat`에 저장합니다. 결과는 테스트 관측치 수 × 트리 개수 크기의 행렬입니다.
    - `sapply()`는 리스트의 각 요소에 같은 함수를 적용한 뒤 결과를 하나로 묶어 주는 함수입니다. `sapply(fits, predict, newdata = test_data)`라고 쓰면 `fits`에 담긴 트리를 하나씩 꺼내 `predict(트리, newdata = test_data)`를 실행합니다. 첫 번째 인수는 반복할 대상, 두 번째는 적용할 함수이고, 그 뒤에 붙인 인수인 `newdata`는 함수를 호출할 때마다 그대로 전달됩니다. 앞서 `for` 루프로 썼던 반복을 한 줄로 줄인 것과 같습니다.
    - 트리 하나의 예측 결과는 테스트 관측치 수만큼의 값을 가진 벡터입니다. `sapply()`는 길이가 같은 벡터들이 모이면 이를 열 방향으로 이어 붙여 행렬로 만들어 주기 때문에 `pred_mat`은 테스트 관측치 수 × 트리 개수 크기의 행렬이 됩니다.
  - `rowMeans()`로 행별 평균을 구해 `bag_pred`에 저장합니다. 배깅은 같은 관측치에 대한 여러 트리의 예측을 평균을 내는 방법이므로 평균은 행 방향으로 구해야 합니다. `rowMeans(pred_mat)`으로 각 행의 평균을 계산해 `bag_pred`에 저장하면 관측치마다 하나씩, 테스트 관측치 수만큼의 최종 예측이 나옵니다.

**3단계. 성능 비교**

마지막으로 트리 하나만 썼을 때와 배깅했을 때의 성능을 비교합니다. 배깅이 예측 성능을 개선했는지 확인해 보세요.

  - `pred_mat[, 1]`은 첫 번째 트리 하나의 예측입니다. 이것으로 `rmse_single`을 계산합니다.
  - `bag_pred`로 `rmse_bag`을 계산해 나란히 출력합니다.

## Task 2-2. 랜덤 포레스트

랜덤 포레스트는 배깅에 훈련에 사용하는 예측변수를 무작위로 선택하는 하나의 요소를 더합니다. 분할마다 후보로 올릴 예측변수를 무작위로 제한해 트리들 사이의 상관을 낮추는 것입니다.

이 실습에서는 `ranger` 패키지를 사용합니다. R의 랜덤 포레스트 구현으로는 `randomForest`가 가장 오래됐지만, `ranger`는 C++를 기반으로 만들어진 후발 주자이지만, 더 다양한 기능을 제공하고, 예측변수가 많거나 표본이 클 때 더 빠릅니다.

`ranger`는 회귀에서 OOB(out-of-bag) MSE를 `prediction.error`에 담아 둡니다. 부트스트랩은 복원추출이므로 각 트리를 학습할 때 뽑히지 않은 관측치가 약 37% 남고, 이 관측치들로 추정한 오차가 OOB 오차입니다. 검증 데이터를 따로 떼지 않아도 되므로 하이퍼 파라미터 탐색에 그대로 쓸 수 있습니다. 성능 평가 단계에서는 여기에 제곱근을 취해야 RMSE가 됩니다.

  - `ranger()` 함수에 `formula = form`, `data = train_data`를 넣어 훈련을 실행하고 그 결과를 `fit_rf`에 저장합니다. `respect.unordered.factors = "order"`는 순서 없는 범주형 변수를 다루는 방식으로, 범주를 결과변수 평균 순으로 정렬해 분할 후보를 찾습니다. 범주 수가 많을 때 계산이 빨라지고 분할도 안정적입니다. `verbose = FALSE`로 훈련 과정의 출력은 끕니다.
  - `fit_rf$prediction.error`는 OOB(out-of-bag) 오차입니다. 각 트리를 학습할 때 부트스트랩에서 뽑히지 않은 관측치로 계산한 예측 오차로, 별도의 검증 데이터 없이도 성능을 가늠할 수 있습니다. 회귀에서는 MSE로 저장되므로 제곱근을 취해 `oob_rmse_rf`에 저장합니다.
  - `predict()`에 `fit_rf`와 `data = test_data`를 넣어 예측값을 계산하고 `pred_rf`에 저장합니다. `ranger`의 `predict()`는 인수 이름이 `newdata`가 아니라 `data`이고, 결과는 예측값 외에 여러 정보를 담은 리스트이므로 `$predictions`로 꺼내야 합니다.
  - 테스트 RMSE를 `rmse_rf`에 저장하고 배깅의 결과와 나란히 출력합니다. 랜덤 포레스트는 분할마다 변수를 일부만 후보로 삼아 트리 간 상관을 낮추므로, 배깅보다 오차가 조금 더 줄어드는 것이 일반적입니다.

## Task 3-1. 패키지없이 구현하는 부스팅

부스팅은 약한 학습기를 순차적으로 쌓아 예측을 개선하는 방법입니다. 여기서도 패키지에 맡기지 않고 그 과정을 직접 작성해 봅니다. 약한 학습기로는 분할이 하나뿐인 회귀 트리, 즉 stump를 사용합니다. Stump 하나는 예측변수 전체 중 딱 하나를 골라 한 번만 자르는 모형이므로 예측력이 매우 낮습니다. 그런 모형을 100개 쌓으면 어떻게 되는지를 살펴보는 것이 이 과제의 목적입니다.

먼저 stump 하나를 훈련 데이터에 적합해 `stump1`에 저장합니다.

  - `rpart()`에 `y_train ~ .`을 넣습니다. 왼쪽에는 앞에서 만든 결과변수 벡터를, 오른쪽 `.`에는 `data`로 넘긴 데이터프레임의 모든 열을 쓴다는 뜻입니다.
  - `data = x_train`으로 예측변수만 담긴 데이터프레임을 넘깁니다.
  - `maxdepth = 1`로 분할을 한 번만 하도록 강제합니다.
  - `cp = 0`으로 복잡도 페널티를 없앱니다. `maxdepth`가 이미 제약이므로 페널티까지 걸면 분할이 아예 일어나지 않을 수 있습니다.

성능은 훈련 RMSE로 확인합니다. 잔차를 계산해 주는 `residuals()` 함수를 쓰면 `y_train - predict(stump1)`을 직접 계산하지 않아도 잔차를 바로 얻을 수 있습니다. 이 잔차를 제곱해 평균 내고 제곱근을 취한 값을 `rmse_stump1`에 저장합니다.
  - 비교 기준으로 훈련 데이터의 평균만으로 예측한 영모형의 RMSE도 `rmse_null`에 저장합니다.

이제 부스팅의 동작을 한 번 수행합니다. 첫 stump가 설명하지 못한 부분, 즉 잔차를 새로운 결과변수로 삼아 두 번째 stump를 적합합니다.

  - `residuals(stump1)`로 첫 stump의 잔차를 꺼내 `r1`에 저장합니다.
  - `rpart()`에 `r1 ~ .`을 넣고 나머지는 그대로 두어 `stump2`를 적합합니다. 예측변수는 그대로이고 결과변수만 바뀌었습니다.
  - `predict(stump1) + predict(stump2)`로 두 예측을 더해 `pred2`에 저장합니다. 평균이 아니라 **합**입니다. 두 번째 stump가 예측하는 것은 결과변수가 아니라 첫 번째가 남긴 오차이므로, 그 오차분을 더해 주어야 원래 척도의 예측이 됩니다.

## Task 3-3. (선택사항) XGBoost

`xgboost`는 트리를 기저 학습기로 쓰는 부스팅의 고성능 구현입니다. 2차 근사와 계산 최적화로 속도와 성능을 끌어올렸습니다. `rpart`가 공식과 데이터프레임을 받는 것과 달리 `xgboost`는 행렬을 입력으로 받으므로, 데이터를 먼저 변환해야 합니다. 1강에서 `glmnet`을 쓸 때와 같은 단계입니다.

  - `model.matrix(rx_num ~ . - 1, data = train_data)`으로 예측변수 행렬을 만들어 `x_mat_train`에 저장합니다. `- 1`은 절편 열을 빼라는 뜻입니다. 같은 방식으로 `x_mat_test`도 만듭니다.
  - `xgb.DMatrix()`에 `data = x_mat_train`, `label = y_train`을 넣어 `dtrain`에 저장합니다. `xgboost`가 내부적으로 쓰는 형식입니다.
  - `xgb.cv()`에 `data = dtrain`, `nrounds = 200`, `nfold = 10`, `verbose = FALSE`를 넣어 `xgcv`에 저장합니다. Task 3-2에서 손으로 그렸던 곡선을 함수 하나로 얻는 셈입니다.
  - `which.min(xgcv$evaluation_log$test_rmse_mean)`으로 최소 지점의 반복 번호를 찾아 `nrounds_best`에 저장합니다.
  - `xgb.train()`에 `nrounds = nrounds_best`를 넣어 `xgb_final`에 저장하고, 테스트 RMSE를 `rmse_xgb`에 저장합니다.
